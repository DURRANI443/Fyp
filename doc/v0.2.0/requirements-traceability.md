# Requirements traceability

Version: v0.2.0  
Date: 2026-10-24, Asia/Karachi

Stable IDs originate in the immutable [v0.1.0 requirements](../v0.1.0/requirements/software-requirements.md). An implemented feature below is not a claim that every original acceptance criterion is satisfied. **Partial** identifies a deliberate scope difference or unverified portion. Test names identify executable checks; consolidated outcomes and environment details are recorded in [verification](verification.md).

Evidence groups:

- **CORE**: [backend/tests/test_core.py](../../backend/tests/test_core.py).
- **SUPPORT**: [backend/tests/test_support_workflows.py](../../backend/tests/test_support_workflows.py). All 25 support cases passed within both the 64-case SQLite suite and the independently executed 64-case PostgreSQL 17.11 suite.
- **AI**: [backend/tests/test_ai.py](../../backend/tests/test_ai.py). Provider cases use HTTPX mock transports, not a real key.
- **UI**: [workflow tests](../../frontend/src/workflows.test.tsx) and [transport tests](../../frontend/src/api.test.ts).
- **BROWSER**: [Playwright workflows](../../frontend/e2e/workflows.spec.ts) exercise the built UI and actual API against an isolated demo database.
- **EVAL**: [evaluation script](../../backend/scripts/evaluate.py), [synthetic intent groups](../../data/intents/v1/dataset.json), [retrieval cases](../../data/retrieval/v1/cases.json).
- **DOCS**: [documentation checker](../../scripts/check_docs.py), [capture tool](../../scripts/capture_baseline.py), [diagram renderer](../../scripts/render-diagrams.mjs).

## Interpretation of results

The original planned test labels (`T-AUTH`, `T-CANCEL`, and others) remain useful categories, but the function names above are the executable implementation. A green test demonstrates its assertions, not complete satisfaction of a broad requirement. In particular, keyless HTTPX tests prove adapter decisions against synthetic responses; they do not prove a current OpenRouter route accepts a real request. PostgreSQL behavior has its own executed evidence, and neither database's workflow results imply pgvector is present.
