# Change log

## v0.1.0 - 2026-10-24

Initial documentation baseline; no prior captured version.

### Added

- Canonical `agent.md` and repository entry-point instructions.
- Singular `doc/` directory with named version baselines and hash-based integrity checking.
- Scope, requirements, use cases, traceability, and incremental SDLC/evaluation process.
- React/TypeScript, FastAPI, PostgreSQL/pgvector, local embedding/classification, and restricted OpenRouter design.
- Open-source license references and a distinction between a free hosted service and an open-source component.
- Planned architecture, data, support, ticket-state, and SDLC diagrams.
- MIT project license, environment-variable examples without credentials, and ignore rules.

### Limitations

- Product features, database migrations, training, live inference, and application tests are not implemented or run.
- Free inference depends on external model availability and quotas; no API key is included or needed for this baseline.
- Diagram exports and documentation-check evidence are listed in the verification record rather than inferred from source-file presence.
